# PAC-SAYAJIN

PAC-SAYAJIN e um jogo inspirado em Pac-Man, com tema Dragon Ball.

Este projeto foi feito usando **Codex GPT-5.4**.

## Jogar

`https://jscaramal.github.io/pacsayajin/`

## Controles

- `Setas` ou `WASD`: movimento
- `Arraste na tela`: movimento no celular
- `Espaco`: pausa no desktop
- `2 toques na tela`: pausa no celular
- `Start`: inicia a partida com o nick atual
- `Reiniciar`: reinicia o jogo
- `Info`: abre o tutorial dentro do jogo

## Regras

- Coma todas as bolinhas do mapa para limpar a fase.
- As bolinhas grandes ativam um poder temporario.
- Durante o poder, os fantasmas comuns ficam vulneraveis.
- Se encostar em um fantasma fora do poder, voce perde vida.
- Ao limpar o `Level 1`, o jogo libera o `Level 2`.
- No boss, o inimigo alterna entre momentos de descanso e investidas rapidas.
